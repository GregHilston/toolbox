## Rebuild (heavy, not while gaming)

From a foundation checkout of branch `foundation-orch` after Greg merges it, or from the worktree:

```
cd ~/Git/toolbox/nixos && just ft foundation   # test first
just fr foundation                             # then switch
```

Before the switch, move the hand-made pi files aside so home-manager owns them: `mv ~/.pi/agent/settings.json ~/.pi/agent/settings.json.hand` (home-manager backs up the rest). Then run `nix profile list` and `nix profile remove pi-coding-agent _1password-cli`, so the config's copies win.
Put `LITELLM_API_KEY` in the shell from `nixos/secrets/.env` (run `just secrets` in `nixos/` there), since `generateModelsJson` reads it from the environment.
